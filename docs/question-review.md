# 문항 검토·출처·이용 조건

작성일: 2026-10-30 (한국 시간). 기출 원문 0, 복원 0, 자체 제작 1,000.
기출·복원 자료는 복제하지 않았다. 모든 year/session은 null이다.

## 실제 작성·검토 범위

- AI 일반 지식 기반의 새 개념 원고 100개. `scripts/concepts.tsv`에 문제·정답·오답·해설을 보관한다.
- 계산은 15가지 공식 × 서로 다른 입력 60개 = 900개 숫자 조건 변형이다. 900가지 독립 개념이나 기출이 아니다.
- 독립 학습 유형은 개념형 100 + 계산 family 15 = 115개다. 전체 자격증 범위의 충분한 대표성을 입증하지 않는다.
- 엔진·섀시·전기전자·안전의 기본 원리, 조건의 한정, 정답과 오답의 구분 및 해설의 일관성을 작성 과정에서 내부 검토했다. AI 자기 검토이며 독립된 사람의 검수는 아니다.
- 계산 생성은 Python Decimal, 수치 검증은 별도 TypeScript 수식으로 수행한다. 단위·반올림·정답 위치·동치 보기·입력 조합과 ID/본문/보기 재배열 중복을 검사한다.
- 의미 중복 검토: 100개 개념 원고를 주제별로 확인했다. 배터리 단자 분리/연결, 캠축 개념/계산 등 관련 주제는 학습 행동이나 질문 조건이 다르다. 계산 변형은 의도적 유사 문항으로 family에 묶었다. 기계적 중복 제거가 의미 중복 부재를 보증하지 않는다.
- 시험 추출에서는 개념형 각각과 계산 family 각각에 1차 추출 슬롯을 부여하므로 기본 은행의 60문항 시험에는 동일 계산 family가 겹치지 않는다. 로컬 은행이 적으면 고유 ID로 보충한다.
- `reviewed`는 위 내부 검토와 자동 검사를 뜻한다. 공식 출제기준 대조·외부 전문가 검수·실제 시험 적합성 인증은 아니다. 기출 원문 검증 완료를 뜻하지 않는다.
- 공식 정비 수치·법령 한계값을 외워야 하는 문제는 확인 없이 만들지 않았다. 실제 차량 정비는 제조사 최신 매뉴얼과 자격·안전절차를 따라야 한다.

현재 학습용 설정은 자동차정비 단일 통합 과목, 엔진/섀시/전기전자/안전 topic,

공식 단원별 문항 비중은 주장하지 않는다. 공식 재현 시험으로 간주하지 말아야 한다.

## 재현

`python3 scripts/generate_bank.py`로 고정 ID·순서·보기 회전을 재생성한다. 난수 시드는 쓰지 않는다.
`npm test`는 JSON 문항 전체와 별도 계산 경로를 검사한다. 개념 문장의 의미·출제 적합성은 자동 테스트가 증명하지 않는다.
문항 수 부족은 0개이나, 공식 대조와 외부 전문가 검수는 별도로 미완료다.
